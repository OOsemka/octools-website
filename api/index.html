API Reference

REST API for catalog, stats, and version data.

Overview

The OCT API is served at https://api.octools.net via Cloudflare Workers. All endpoints return JSON and support CORS.

Base URLhttps://api.octools.net
FormatJSON
AuthNone for reads; Bearer token for admin writes
Rate limit20 writes/min per IP
PrivacyNo PII collected — only anonymous SHA-256 cluster hash for rating dedup

Endpoints

GET /health

Health check. Returns {"status":"ok"}.

GET /v1/catalog

Full catalog with stats (downloads, average rating) and version rows merged per tool.

GET /v1/stats

Download counts and ratings for all tools.

GET /v1/versions

All version rows across all tools (version, channel, openshift, image, gitRef).

GET /v1/versions/:toolId

Version rows for a single tool.

# Example
GET /v1/versions/oct-baremetal
POST /v1/stats/download

Increment the download counter for a tool. Called by the storefront on Add.

# Request body
{
  "toolId": "oct-baremetal"
}
POST /v1/stats/rating

Upsert a star rating. One rating per cluster per tool (deduped by cluster hash).

# Request body
{
  "toolId": "oct-baremetal",
  "clusterHash": "a1b2c3d4...sha256",
  "stars": 5
}
DELETE /v1/stats/rating

Remove a rating. Body is the same as the POST (minus stars).

# Request body
{
  "toolId": "oct-baremetal",
  "clusterHash": "a1b2c3d4...sha256"
}
POST /v1/versions

Admin only. Upsert a version row. Requires Authorization: Bearer <token>.

# Request body
{
  "toolId": "oct-baremetal",
  "version": "1.0.0",
  "channel": "stable",
  "openshift": ["4.21", "4.22"],
  "image": "quay.io/org/oct-baremetal:1.0.0-ocp4.22",
  "gitRef": "v1.0.0"
}

# Header
Authorization: Bearer <admin-token>

CORS

All endpoints return permissive CORS headers. The API is designed to be called from OpenShift Console plugins running in the browser.

Rate Limiting

Write endpoints (POST, DELETE) are rate-limited to 20 requests per minute per IP. Read endpoints are not rate-limited.

Privacy

The API collects no personally identifiable information. Ratings use an anonymous SHA-256 hash of the cluster ID for deduplication. No cookies, no tracking, no analytics.
