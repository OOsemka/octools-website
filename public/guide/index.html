Getting Started

Install the storefront and add community tools to your OpenShift Console.

Prerequisites

  • OpenShift 4.21 or later
  • cluster-admin access (required for ConsolePlugin installation)
  • oc CLI logged in to your cluster

Install the Storefront

The OCT storefront is itself an OpenShift dynamic console plugin. Apply the install manifest:

oc apply -f https://raw.githubusercontent.com/OOsemka/oct-storefront/main/deploy/install.yaml

This creates the oct-storefront namespace, Deployment, Service, and ConsolePlugin CR, then enables the plugin on the console.

Navigate to Community Tools

After the storefront pod is Running, refresh the OpenShift Console. A new Community Tools section appears in the left sidebar with hubs for:

  • Compute — bare metal, virtualization tools
  • Storage — benchmarks, data management
  • Network — bonding, VLAN, network policy tools
  • Management — banners, dashboards, utilities

Browse the Catalog

Each hub lists available community extensions as tiles. Every tile shows the tool name, description, category, version, star rating, and download count.

Add an Extension

Click Add on any tile. The storefront:

  1. Creates a namespace for the extension (e.g. oct-baremetal)
  2. Applies the bundled deploy YAML (Deployment, Service, ConsolePlugin, any PVCs)
  3. Appends the plugin to the console spec.plugins list
  4. Waits for the plugin to become Ready

If the extension requires storage (like Bare Metal Hosts), the storefront shows a StorageClass picker.

Enable / Disable

Toggle an extension off without uninstalling. The workload keeps running; only the console route is removed. Toggle it back on any time.

Update

When a new version is available for your OpenShift minor, an Update button appears on the tile. Updates are explicit — never automatic. Click to pull the new version.

Star Rating

Rate tools from 1–5 stars to help the community surface the most useful extensions. Ratings are anonymous (SHA-256 cluster hash for deduplication — no PII).

External Extensions

If a tool isn't in the catalog yet, you can add it manually:

  1. Click Add external extension
  2. Paste a CommunityTool YAML manifest
  3. The storefront installs it with an orange badge to distinguish it from catalog tools

External tool stats stay cluster-local. See oct-hello-external for a working example.

Uninstall

To remove all OCT extensions from your cluster:

bash <(curl -s https://raw.githubusercontent.com/OOsemka/oct-storefront/main/deploy/uninstall.sh)

This removes all oct-* namespaces, ConsolePlugins, and RBAC. System plugins are not affected.
