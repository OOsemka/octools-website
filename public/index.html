Community project. Not officially supported by Red Hat.

What’s New

Recent additions and major updates across OCT extensions

Network DHCP New

Create dnsmasq-based DHCP servers on NAD VLAN networks with IP pools, gateway, DNS, and per-VM MAC reservations. Automatic SCC creation for NET_RAW, NET_BIND_SERVICE, and NET_ADMIN capabilities.

Network VLAN New

Create VLAN networks for VMs and pods. Supports Linux bridge NADs and OVN ClusterUserDefinedNetworks with localnet topology.

Network Bridge New

Create Linux or OVS bridges on cluster nodes with NMState. Tag VLANs, configure OVN bridge-mappings, and apply per-MachineConfigPool.

Storefront v1.3 Update

Version-aware cache seeding that auto-refreshes on upgrade, public API metadata enrichment, and installed.json persistence across restarts.

Bare Metal Hosts Update

Register and deploy bare metal nodes with Redfish BMC discovery, OS image caching via discovery-service, and cloud-init provisioning.

Storage Bench Update

FIO-based storage benchmarking with RADOS tests for Ceph. Test any StorageClass with configurable block sizes and queue depths.

Banner Update

Customize the OpenShift Console banner, logo, and branding. Set text, colors, and appearance from a simple UI.

Quick Start

Three steps to community tools in your OpenShift Console

Install the Storefront

Apply the install manifest to deploy the OCT storefront plugin into your cluster.

oc apply -f https://raw.githubusercontent.com/OOsemka/oct-storefront/main/deploy/install.yaml

Browse the Catalog

Open the OpenShift Console. Navigate to Community Tools in the sidebar. Browse extensions by category: Compute, Storage, Network, Management.

Add Extensions

Click Add on any tile. The storefront creates the namespace, deploys the plugin, and enables it in your console.

Uninstall

To remove all OCT extensions from your cluster, run the uninstall script:

bash <(curl -s https://raw.githubusercontent.com/OOsemka/oct-storefront/main/deploy/uninstall.sh)

Removes all oct-* namespaces, ConsolePlugins, and RBAC. System plugins are not affected. Learn more →
